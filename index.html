rv32i_processor.v #01
Verilog RISC-V RTL Vivado Basys3

RV32I RISC-V
Processor

Fully functional single-cycle RV32I processor implementing the base integer ISA from scratch — Harvard architecture with complete datapath and control.

  • Designed single-cycle processor datapath in Verilog (IF, ID, EX, MEM, WB stages)
  • Implemented 32-bit ALU supporting ADD, SUB, AND, OR, XOR, SLT, SLL, SRL, SRA
  • Built instruction decoder and main control unit for all RV32I instruction types (R, I, S, B, U, J)
  • Designed 32-register file with dual-read, single-write ports; implemented IMEM and DMEM
  • Verified 37-instruction coverage using 10-testbench regression suite with waveform analysis
  • Synthesized and deployed on Digilent Basys3 FPGA via Xilinx Vivado toolchain

gnn_power.py #04
PyTorch GNN Python GCN/GAT EDA

AI Gate-Level
Power Prediction

ML pipeline to estimate dynamic power consumption at gate level — using Graph Neural Networks on circuit DAGs to outperform traditional estimation methods.

  • Modeled gate-level netlists as directed acyclic graphs (DAGs) with node features (fanin, logic depth, gate type)
  • Implemented GCN and GAT architectures in PyTorch Geometric for circuit graph learning
  • Built full prediction pipeline: netlist parsing → feature extraction → GNN training → power estimation
  • Outperformed Random Forest baseline: R²=0.2169 vs 0.1687 (28% improvement)
  • Applied SHAP explainability to identify which circuit features drive power most significantly
  • Generated 2,000 synthetic gate-level circuit DAGs with annotated dynamic power labels
